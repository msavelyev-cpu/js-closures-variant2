# Практична робота №8

## Тема

Замикання (Closures) та функціональні патерни в JavaScript.

## Виконав

Савельєв Михайло, група АЛК-43

## Опис проєкту

У проєкті реалізовано банківську систему та набір функціональних утиліт із використанням замикань.

### Реалізовані патерни

#### Closure (Замикання)

Використано для створення приватного балансу та історії транзакцій банківського рахунку.

#### Module Pattern

Функціональні утиліти організовані у вигляді окремих модулів.

#### Memoization

Реалізовано кешування результатів функцій для уникнення повторних обчислень.

#### Currying

Реалізовано каррінг для часткового застосування аргументів.

## Функціонал

### Банківська система

* createAccount(owner, initialBalance)
* deposit(amount)
* withdraw(amount)
* getBalance()
* getTransactionHistory()

### Functional Toolkit

* compose(...fns)
* pipe(...fns)
* partial(fn, ...args)

### Додатково

* memoize(fn)
* curry(fn)
